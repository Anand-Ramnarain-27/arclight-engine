## Phase 2: textures, camera, scene viewport and glTF models

Arclight now loads and draws real 3D models. The scene renders into its own dockable *Scene* panel, seen through an editor camera with a depth buffer, over an infinite grid. glTF files can be dropped onto the window, and textures are mipmapped and sampled with configurable filtering. Under the hood, GPU resources can be replaced while frames are in flight, and per-draw constants come from a ring buffer.

### What's in it
- **glTF 2.0 models** (`.gltf` and `.glb`): node hierarchies, any accessor layout (interleaved, normalized integers, sparse), strips and fans, flat normals when a file has none, base colour materials with alpha mask/blend and double-sided faces, and samplers. The *Lantern* sample opens at start-up. Drop any glTF file onto the window to open it, and switch the shading to base colour, normals or texture coordinates to check an import.
- **Editor camera**: fly (right drag + W A S D, Q / E), orbit (Alt + left drag), pan (middle drag), dolly (wheel) and F to focus on the origin, with an axis gizmo and a *Camera* menu in the Scene panel.
- **Depth buffer with reversed-Z**, which can be switched off to compare. The texture demo has a z-fighting test that shows the difference.
- **Infinite anti-aliased grid** with X and Z axes, fading into the distance.
- **Scene viewport**: the scene renders into a texture sized to the *Scene* panel in pixels (full resolution on Retina), dockable like any other panel.
- **Textures and samplers**: PNG/JPEG/TGA/BMP loading, sRGB-correct mip generation, filtering, address modes, anisotropy and mip bias, explored in the *Texture Demo* panel.
- **Resource lifetimes**: buffers and textures can be destroyed while the GPU still uses them (deferred release on D3D12). Generational handles, a leak report at shutdown and live resource counts in *System Info*.
- **Per-frame constants** through an upload ring buffer (root CBVs on D3D12, buffer slots on Metal).

Full list: [CHANGELOG.md](https://github.com/Anand-Ramnarain-27/arclight-engine/blob/v0.3.0/CHANGELOG.md)

### Downloads
| File | Platform |
|---|---|
| `Arclight-0.3.0-windows-x64.zip` | Windows 10/11, x64, a GPU with Direct3D 12 |
| `Arclight-0.3.0-macos-arm64.zip` | macOS 14+ on Apple silicon |

**Windows:** extract the zip and run `Arclight.exe`. Keep the `Shaders` and `Assets` folders next to it. The build is unsigned, so SmartScreen may warn you. Choose *More info > Run anyway*.

**macOS:** the build is unsigned and not notarized, so macOS blocks it after download. Extract the zip, then in Terminal:
```
cd ~/Downloads/Arclight-0.3.0-macos-arm64
xattr -dr com.apple.quarantine .
./Arclight
```

If you used 0.2.0 before, choose *View > Reset Layout* once to dock the new *Scene*, *Texture Demo* and *Model* panels.

### Editor controls
**Scene panel** (pointer over the scene): right drag to look · W A S D / Q E to fly · Shift for 4x speed · Alt + left drag to orbit · middle drag to pan · wheel to dolly · F to focus on the origin · click a gizmo axis to view along it.

**Everywhere:** F5 play/pause · Shift+F5 stop · F6 step one frame · +/- time scale · 0 reset time scale · F11 capture a GPU frame (when a capture tool is attached) · View > Reset Layout restores the default docking layout.

### Building from source
```
cmake --workflow --preset windows-release   # or macos-release
```
macOS builds also need the [Vulkan SDK](https://vulkan.lunarg.com/sdk/home#mac), which provides DXC. Configuring downloads the dependencies and the sample model, so it needs an internet connection. See the README for IDE setup.
