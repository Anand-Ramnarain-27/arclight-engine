## Phase 1: RHI and first triangle

Arclight now renders through its own GPU layer. A thin rendering hardware interface (RHI) sits on top of Direct3D 12 on Windows and Metal on macOS, and the editor draws a coloured triangle and its whole UI through it. SDL_Renderer is gone.

### What's in it
- RHI with device, swapchain, command list, buffers, shaders and pipelines; two frames in flight
- Direct3D 12 backend: debug layer messages in the Console panel, high-performance GPU selection, flip-model swapchain with resize and tearing support
- Metal backend: `CAMetalLayer` swapchain, semaphore-paced frames, API validation and GPU capture in the Xcode scheme
- Buffers in GPU-only, upload and readback memory, copies and resource-state barriers
- Build-time shader compilation from one HLSL source: DXIL on Windows, and SPIR-V → MSL (SPIRV-Cross) → `.metallib` on macOS
- Graphics pipelines and indexed drawing; the editor draws a triangle from GPU-only vertex and index buffers
- Dear ImGui rendered through the RHI (`imgui_impl_dx12` / `imgui_impl_metal`)
- In-app GPU frame capture: *Debug → Capture GPU Frame* (F11) with RenderDoc, PIX (`--pix`) or Xcode
- System Info panel shows the graphics API, GPU, memory, driver and attached capture tool

Full list: [CHANGELOG.md](https://github.com/Anand-Ramnarain-27/arclight-engine/blob/v0.2.0/CHANGELOG.md)

### Downloads
| File | Platform |
|---|---|
| `Arclight-0.2.0-windows-x64.zip` | Windows 10/11, x64, a GPU with Direct3D 12 |
| `Arclight-0.2.0-macos-arm64.zip` | macOS 14+ on Apple silicon |

**Windows:** extract the zip and run `Arclight.exe`. Keep the `Shaders` folder next to it. The build is unsigned, so SmartScreen may warn you. Choose *More info > Run anyway*.

**macOS:** the build is unsigned and not notarized, so macOS blocks it after download. Extract the zip, then in Terminal:
```
cd ~/Downloads/Arclight-0.2.0-macos-arm64
xattr -dr com.apple.quarantine .
./Arclight
```

### Editor controls
F5 play/pause · Shift+F5 stop · F6 step one frame · +/- time scale · 0 reset time scale · F11 capture a GPU frame (when a capture tool is attached) · View > Reset Layout restores the default docking layout.

### Building from source
```
cmake --workflow --preset windows-release   # or macos-release
```
macOS builds also need the [Vulkan SDK](https://vulkan.lunarg.com/sdk/home#mac), which provides DXC. See the README for IDE setup.
