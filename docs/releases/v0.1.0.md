## Phase 0: Foundations

The first tagged build of Arclight, a C++20 learning engine for Windows and macOS. This release is the groundwork: build system, window and main loop, timing, input, math, and a dockable editor shell. **There is no 3D rendering yet.** The editor UI is drawn through SDL_Renderer until the engine's own D3D12 and Metal renderer arrives in Phase 1.

### What's in it
- CMake build for Visual Studio 2022 (Windows x64) and Xcode (macOS, Apple silicon), with dependencies pinned to exact versions
- SDL3 window and an application loop built from ordered modules
- Logging and asserts built on `std::format` and `std::source_location`
- Frame timing plus a game clock with play, pause, stop, single-step and time scale
- Keyboard, mouse and gamepad input
- Math library (vectors, quaternions, matrices) with unit tests
- Dear ImGui docking editor with Console, Performance, Playback and System Info panels

Full list: [CHANGELOG.md](https://github.com/Anand-Ramnarain-27/arclight-engine/blob/v0.1.0/CHANGELOG.md)

### Downloads
| File | Platform |
|---|---|
| `Arclight-0.1.0-windows-x64.zip` | Windows 10/11, x64 |
| `Arclight-0.1.0-macos-arm64.zip` | macOS 14+ on Apple silicon |

**Windows:** extract the zip and run `Arclight.exe`. The build is unsigned, so SmartScreen may warn you. Choose *More info > Run anyway*.

**macOS:** the build is unsigned and not notarized, so macOS blocks it after download. Extract the zip, then in Terminal:
```
cd ~/Downloads/Arclight-0.1.0-macos-arm64
xattr -dr com.apple.quarantine .
./Arclight
```

### Editor controls
F5 play/pause · Shift+F5 stop · F6 step one frame · +/- time scale · 0 reset time scale · View > Reset Layout restores the default docking layout.

The window layout is saved to `imgui.ini` in the folder you run from.

### Building from source
```
cmake --workflow --preset windows-release   # or macos-release
```
This configures, builds, tests and writes the zip to `build/packages/`. See the README for IDE setup.
