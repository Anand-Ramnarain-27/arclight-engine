## Phase 4: lighting and PBR

Arclight now lights its scenes. Directional, point and spot lights shine on physically based materials in HDR, with normal maps, ambient occlusion and emission, and an HDR sky lights everything through image-based lighting. Textures are cooked to block-compressed formats, a quarter of their size or less on the GPU. Any material can switch to toon shading with outlines, per object, so a stylized character and a physically lit room can share a scene.

### What's in it
- **Lights**: directional, point and spot lights in glTF's units (lux and candela), added with *GameObject > Light*, edited in the Inspector and selected by their icons in the Scene view. Scenes without lights get a default sun.
- **HDR and tone mapping**: the scene renders in linear light, then exposure and a tone curve (Khronos PBR Neutral by default; ACES, Reinhard or none) bring it to the screen.
- **Physically based materials**: Cook-Torrance GGX with glTF's metallic-roughness model, normal maps (MikkTSpace tangents when the file has none), ambient occlusion and emission. Lambert, Phong and Blinn-Phong are in the *Lighting* menu to compare, with debug views for each term.
- **Image-based lighting**: load an equirectangular `.hdr` sky (*View > Sky > HDR...*, or *Use as Sky* in the Files panel) and it lights every surface: diffuse from its irradiance, reflections blurred by roughness. Turn it and set its strength in *View > Sky*.
- **Compressed textures**: models and textures are cooked to BC7, BC5 (normal maps) and BC4 (occlusion) by default, or BC1/BC3 with *Small*. The Lantern's textures drop from 85 MB to 21 MB of GPU memory.
- **Toon shading and outlines**: select an object and open *Style* under its Mesh component to switch a material to *Toon* (bands of light or a ramp texture, a hard highlight, a rim light) and give it an outline. For a whole imported room, right-click it in the Hierarchy and use *Shading* to switch everything below it, or the whole scene, at once.

### Downloads
| File | Platform |
|---|---|
| `Arclight-0.5.0-windows-x64.zip` | Windows 10/11, x64, a GPU with Direct3D 12 |
| `Arclight-0.5.0-macos-arm64.zip` | macOS 14+ on Apple silicon |

**Windows:** extract the zip and run `Arclight.exe`. Keep the `Shaders` and `Assets` folders next to it. The build is unsigned, so SmartScreen may warn you. Choose *More info > Run anyway*.

**macOS:** the build is unsigned and not notarized, so macOS blocks it after download. Extract the zip, then in Terminal:
```
cd ~/Downloads/Arclight-0.5.0-macos-arm64
xattr -dr com.apple.quarantine .
./Arclight
```

Cooked assets and your settings are kept in the per-user folder (`%APPDATA%\Arclight\Editor` on Windows, `~/Library/Application Support/Arclight/Editor` on macOS). The cooked formats changed in this version, so the first start cooks the sample model again, which now includes compressing its textures and takes a few seconds.

### Editor controls
**Scene panel** (pointer over the scene): left click to select · W / E / R move / rotate / scale gizmo · Ctrl while dragging to toggle snapping · right drag to look · W A S D / Q E to fly · Shift for 4x speed · Alt + left drag to orbit · middle drag to pan · wheel to dolly · F to frame the selection.

**Everywhere:** Ctrl+N / O / S / Shift+S new, open, save, save as · Delete · Ctrl+D duplicate · F5 play/pause · Shift+F5 stop · F6 step one frame · +/- time scale · 0 reset time scale · F11 capture a GPU frame (when a capture tool is attached) · View > Reset Layout restores the default docking layout. On macOS, Cmd replaces Ctrl.

### Building from source
```
cmake --workflow --preset windows-release   # or macos-release
```
macOS builds also need the [Vulkan SDK](https://vulkan.lunarg.com/sdk/home#mac), which provides DXC. Configuring downloads the dependencies and the sample model, so it needs an internet connection. See the README for IDE setup.
